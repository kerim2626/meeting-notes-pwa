# Юзабилити-тестирование версии 1.0

Даты: 27–30.07.2026. Формат: модерируемое очное тестирование с размышлением вслух, 25–30 минут на участника, собственные смартфоны участников.

## Цели

1. Создание заметки — не дольше 2 минут без ошибок у 4 из 5 участников.
2. Поиск по слову и по фильтрам — успешно у 80 % участников.
3. Оценка SUS — не ниже 68 баллов.
